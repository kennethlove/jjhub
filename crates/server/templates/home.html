Run your own forge, built around Jujutsu.

jjhub is self-hosted repository hosting for jj and git. Merge reviews anchor to change-ids and survive every history rewrite you make.

Run it yourself View on GitHub

What ships today

The shipped list from v0.9.0 — every row below already runs in jjhub.

Change-anchored merge reviews

The merge request follows the change, not the ref: edit-in-place revisions, stacks from the graph, review attached through rebase, squash, and rewrite.

Mail that delivers

Every message ships as an HTML and plain-text pair with a per-send readout on /admin and a clear retry when a send fails.

Moderation built in

Suspend and unsuspend accounts, takedown and restore repositories — reason quoted, every action written to an audit CSV.

Rate limits and SSH transport

Per-action rate limits on HTTP and SSH, and jj and git over SSH alongside smart HTTP.

Git smart HTTP

Plain git clone, fetch, and push work next to jj on the same repositories.

One docker compose up

jjhub and Postgres in one stack. Configuration lives in environment variables: SMTP for delivery, rate-limit budgets, and your operator handle.

1

Bring the stack up

curl -O https://raw.githubusercontent.com/kennethlove/jjhub/main/docker-compose.yml
docker compose up -d
2

Point SMTP at it

Set the SMTP host, credentials, rate limits, and operator handle in the environment file. The README's staging proof walks the first live send end to end.

Setup, backup notes, and reverse-proxy examples live in the README.
